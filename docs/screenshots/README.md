# Screenshots

Drop the images here using exactly these filenames; the root `README.md` references them.

| Filename | What to capture |
| --- | --- |
| `01-pipeline-board.png` | The pipeline board artifact, full page |
| `02-first-session.png` | A fresh session: the welcome line, then the CV intake summary |
| `03-fit-assessment.png` | A fit assessment page: the verdict block and the gap table |
| `04-interview-prep.png` | A prep page at phone width (~400px) |
| `05-mock-interview.png` | The live mock: a question, an answer, the grading |

PNG or JPG both work. Keep them under ~1MB each so the repo stays light, and check that nothing in frame shows a real salary figure, phone number or email address you would rather not publish.
